UniDocs is a web application for universities to create, manage, and verify official student documents.

The main purpose of the project is to simplify the process of requesting university documents. Students will be able to request documents online instead of visiting university departments manually.

Examples of supported documents:

Enrollment Certificate
Student Status Letter
Internship Confirmation Letter
Transcript Request
Visa Support Letter
Graduation Confirmation

Each generated document will have a unique document ID and QR code. Employers, embassies, universities, or other organizations will be able to verify whether the document is valid.

Main Users
Students
University administrators
Document verifiers
Main Features
